# ProjetosCrud

🎮 Sistema de Controle Remoto

📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema de controle remoto utilizando a linguagem Python.

O programa simula as funcionalidades básicas de um controle remoto, permitindo cadastrar um dispositivo e interagir com suas funções por meio de um menu no terminal.

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de lógica de programação, estruturas condicionais, estruturas de repetição e manipulação de variáveis.

⚙️ Funcionalidades

- Cadastro: permite cadastrar um controle remoto.
- Ligar e desligar: altera o estado de funcionamento do controle.
- Controle de volume: permite aumentar ou diminuir o volume.
- Troca de canais: possibilita navegar entre os canais disponíveis.
- Consulta: permite visualizar informações do controle cadastrado.

💻 Tecnologias utilizadas

- Python 3
- Visual Studio Code
- Git
- GitHub

🚀 Como executar o projeto

1. Certifique-se de ter o Python 3 instalado.
2. Faça o download ou clone este repositório.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute o arquivo principal pelo terminal:

python main.py
